# JIDU6111 driver audit, 26 November 2026

The OpenWrt search returned 196 unique open PRs across the Qualcomm target label, ath11k, mac80211, firmware and board/PHY identifiers. Follow-up searches covered WCSS, PCIe, NAND, USB and thermal support. The review also checked the open Qualcomm board-data PRs and the upstream Linux ath11k, PPE and QCA807x histories. OpenWrt main was pinned at `f76496253dfc`, with Linux 6.18.64 and mac80211 backports 7.2.

The build uses the ath11k portions of #25807 and #26253, the retry-statistics patch from #25982, and the hotplug fix from #26655. The second #26655 commit changes packet-steering policy on RSS radios.

## Other relevant results

- Backports already include the receive coalescing fix in [#24658](https://github.com/openwrt/openwrt/pull/24658), the recent upstream ath11k management-TX and regulatory fixes, and the equivalent locked mac80211 access discussed in [#26056](https://github.com/openwrt/openwrt/pull/26056). The Ethernet receive fix in #25569 covers the same freed-buffer path as [#24191](https://github.com/openwrt/openwrt/pull/24191). The earlier firmware already applied a compatible RXDMA isolation backport from [#24254](https://github.com/openwrt/openwrt/pull/24254).
- JIDU6111 uses PSGMII. [#26007](https://github.com/openwrt/openwrt/pull/26007) addresses a QSGMII-specific PHY sequence. Linux 6.18.64 already has the checked QCA807x GPIO return and DSP bias fixes. Shared IPQ5018/QCN6122, ath12k and qca8k changes target different devices or drivers.
- The build keeps the board definition from [#26498](https://github.com/openwrt/openwrt/pull/26498). [#26551](https://github.com/openwrt/openwrt/pull/26551) and [#25869](https://github.com/openwrt/openwrt/pull/25869) are alternative board ports with their own device tree and upgrade logic. Both shipped calibration files match [board-data PR #193](https://github.com/openwrt/firmware_qca-wireless/pull/193) byte for byte.
- [#21495](https://github.com/openwrt/openwrt/pull/21495) and [#24713](https://github.com/openwrt/openwrt/pull/24713) propose alternative memory changes. The images use the existing smaller RX rings with private RXDMA caches. [#24178](https://github.com/openwrt/openwrt/pull/24178), [#26075](https://github.com/openwrt/openwrt/pull/26075) and [#25981](https://github.com/openwrt/openwrt/pull/25981) are offload, fast-path or scheduler redesigns. [#26959](https://github.com/openwrt/openwrt/pull/26959) changes unencrypted mesh setup across three packages. The hardware mode, 6 GHz and alternate board-data submissions target modes or board configurations outside these JIDU6111 profiles.
